# Security

The plugin handles Google OAuth tokens (via GNOME Online Accounts) and
calendar text. If you find a way to leak a token, run code, or make the panel
open something it should not, please report it privately through
[GitHub security advisories](https://github.com/huligabuliga/Omagoocal/security/advisories/new)
rather than a public issue. The hardening rules are listed in
[CONTRIBUTING.md](CONTRIBUTING.md).
